# JeRRSmy

Jeremy is a graphical RSS aggregator.

## About

Made in Go with Wails and Preact.

## Development

To run in live development mode, run `wails dev` in the project directory. This will run a Vite development
server that will provide very fast hot reload on frontend changes.
To access it in a browser to test the Go methods in the dev tools, access http://localhost:34115.

## Building

To build a redistributable, production mode package, use `wails build`.
